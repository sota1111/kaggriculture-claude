## Motivation (from the Issue)
The existing local oracle (`scripts/eval.py`) only scores a candidate against the **committed
champion** (self-mirror + vs-own-champion). By that oracle the champion looks *dominant* — SOT-2381
recorded soil beating the prior moon-counts-melons champion **20/20 ALL WIN, diff_mean +170519** — yet
the public LB has the champion **out-of-rank (top20未満)**. That gap is oracle drift: the self-mirror
oracle does not reflect the real arena's opponent field. Following kaitofukami's "time-split replay
league" idea, freeze the current **public top-5** kernels' policies as an opponent pool and re-anchor
the A/B on that real field.
