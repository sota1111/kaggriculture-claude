## 提出判定の詳細

- 全子非昇格のため新championなし。`main.py` は moon-198（`7c5a4a2a`）のまま。
- `submission.tar.gz` に埋め込まれた `main.py` sha256 = `7c5a4a2a` は、**標準の best-LB提出**
  （ref 55211714, tarball `e7dfd915`, public **2543.4**）と **byte一致**。tarball のバイトhash
  （`0db3003a…`）が違うのはビルドメタデータ（timestamp）だけ。
- Kaggle は best 提出でランクするため 2543.4 が既に立っている。内容同一の champion を再提出しても
  順位は改善せず、共有の当日 claude 枠（1日2枠/系統）を浪費するだけ。
- よって Issue 規定「artifact fingerprint が前回提出と同一なら『非昇格・新artifactなし』と記録し
  提出成功として扱わない」に従い **非提出**。SOT-2388（arc-agi-2 親集約）の先例と一致
  （dry-run が submit と出るのは tarball byte-hash 差のみで実内容は同一、手動 sha256 照合で非提出が正）。
