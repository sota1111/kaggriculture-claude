# SOT-2261 — Hire farm hands to parallelize tile labor

## Change

Generalize the single-farmer multi-tile router (SOT-2259) into a **multi-worker
router** that HIREs farm hands and services the NW quadrant in parallel.

**Why it helps (throughput).** A lone farmer takes one physical action per turn.
A wheat tile needs ~6 actions per 4-day cycle (plant + water@0,2,3,4 + harvest),
so keeping all 25 NW slots alive needs ~150 actions per 96 turns — the single
farmer is throughput-bound and leaves tiles idle. Hiring 5 hands gives 6 parallel
workers, multiplying tiles serviced per turn.

- **HIRE** every morning (`hour == 0`): `TARGET_HANDS = 5` hands. Hands and their
  per-worker inventories are dissolved by the env each `end_of_day` and re-spawned
  at the shed corners, so hiring repeats daily.
- **Routing:** greedy nearest-unclaimed-task assignment across `[farmer, *hands]`,
  one worker per tile. Priority HARVEST > WATER > PLANT (bounded by seeds on hand,
  so the interpreter's atomic-PLANT seed check never voids a turn) > DIG; else step
  toward the nearest servicing target.
- **Market:** SELL all shed wheat each turn; BUY_SEED buffer sized to open slots.
- Order budget stays under `maxMarketOrdersPerTurn=10` (≤5 HIRE + SELL + BUY_SEED).

## Hire cost / benefit

- `farmHandCostMult=1` (config default). Fibonacci hire cost per day for 5 hands =
  `fib(0..4) = 1+1+2+3+5 = 12/day` → ~**360 over the 30-day game**.
- Verified 150 HIRE orders issued per episode (5/day × 30) and 5 live hands each day.
- Score gain vs champion is **~+5,100**, so hire cost is recovered ~14×.

## Environment / oracle

`kaggle_environments` `kaggriculture` (boardSize 10, turnsPerDay 24,
episodeSteps 720 → 30 days, startingMoney 3000, shedCapacity 100,
farmHandCostMult 1). Score = final money. Head-to-head `env.run([new, champion])`,
new = player 0. (Shared market: both farmers glut wheat, so absolute scores sit
below the SOT-2259 single-agent sweep numbers; the mirror diff is the signal.)
